# תודה תודה

> תלונות הם שומעים כל יום. הגיע הזמן לתודה.

אתר לכתיבת מכתבי תודה והוקרה לפקידים ולנותני שירות שעשו עבודה טובה, כך שהמכתב יגיע לממונים עליהם.

**לזכרה של שוש כהנא ז"ל**, שהקפידה לשלוח מכתבי תודה והערכה בכל פעם שקיבלה שירות טוב.

## איך זה עובד

1. בוחרים משרד או ארגון וממלאים את שם הפקיד/ה.
2. מספרים בקצרה מה קרה ומה בלט בשירות.
3. ממלאים את השם שלכם.
4. האתר מנסח מכתב רשמי בעברית. אפשר לערוך אותו ואז לשלוח אותו בטופס פניות הציבור, במייל או בדואר.

## עקרונות

* **בחינם לגמרי.** אתר סטטי, בלי שרת ובלי מסד נתונים.
* **פרטיות.** הכול רץ בדפדפן של המשתמש, ושום מידע לא נשמר ולא נשלח.
* **עברית מלאה מימין לשמאל**, מותאם לטלפון ולנגישות.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | הדף הראשי |
| `css/style.css` | העיצוב |
| `js/offices.js` | רשימת המשרדים והקישורים (כאן מוסיפים משרדים וכתובות מייל) |
| `js/letter.js` | ניסוח המכתב |
| `js/app.js` | הפעלת הטופס ואפשרויות השליחה |
| `fonts/` | הגופנים Assistant ו-Frank Ruhl Libre (רישיון SIL OFL), מאוחסנים באתר |
| `favicon.svg`, `apple-touch-icon.png`, `og.png` | סמל האתר ותמונת השיתוף |

## מאגר פניות הציבור

`js/offices.js` מכיל כ-27 משרדי ממשלה ושירותים ציבוריים. לכל אחד יש (לפי מה שפורסם) טופס מקוון לפניות הציבור, מייל וכתובת למשלוח בדואר, וגם קישור למקור שממנו נלקחו הפרטים.
הפרטים נאספו באוקטובר 2026 מפרסומים רשמיים: אתרי הגופים, המדריך הממשלתי "לאן לפנות" (2024) ואתר "כל זכות". פרטים שלא נמצא להם מקור רשמי עדכני לא הוכנסו.

הוספת משרד:

```js
{ id: "example", name: "שם המשרד", form: "https://...", email: "pniot@...", postal: "...", sources: ["https://..."] }
```
